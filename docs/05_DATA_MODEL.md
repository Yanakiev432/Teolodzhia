# 05. Data model

## Source record

Authoritative atomic catalog record with sourceKey. Frozen count: **2801**.

## Logical work

Presentation/search grouping built by the workgraph sidecar. Frozen named work candidates: **31**.

## Manifestation

Distinct source record belonging to one logical work. Multiple manifestations may represent editions, scans, versions, or files.

## Scan series

Generic scan page filenames are grouped into four scan series. Frozen scan-series pages: **86**.

## Frozen arithmetic

2801 source records - 149 clustered source records + 31 named logical works + 4 scan series = 2687 logical entries.

Logical reduction: **114**.

## Freshness

Workgraph carries catalog/fingerprint identity. If it no longer matches the active source catalog, work-level operations fail closed.
